# 研究方案与代码对应

## 不变的研究边界

- 图文优先；学生为 Qwen3-VL-8B-Instruct，教师按视觉能力和质检结果另选。
- 一个领域专家、六个维度：image_perception、text_understanding、consistency_verify、emotion_analysis、intent_analysis、fact_conflict_checking。
- 不把情绪、攻击性、普通改写或 AI 配图直接判为事实虚假；允许 insufficient/not_applicable。
- 事实判断、媒体状态、机制、表达策略和基准预测各自保留。
- MMFakeBench 主线；DGM4 作为未见泛化集，不放进训练、开发或案例库。
- 原始 MAR_KDD 保持不变；原 MAR 基线的记忆问题本次未修改。

## 当前实现

| 方案要求 | 入口及实际逻辑 |
|---|---|
| 事件级隔离 | sixdim.split：人工事件映射、规范化精确文本、可选图片字节哈希联合分组；与测试重叠的训练样本排除 |
| 分组可信度 | 未提供完整人工审核映射时标记 provisional，教师生成不能接收 |
| 标签盲化教师 | sixdim.teacher：只向教师传图文和证据白名单，原始标签只供质检 |
| 六维数据 | A 阶段先仅图文观察，再进行有来源事实核验 |
| 学生初稿 | teacher drafts：调用部署好的学生生成初稿，保留模型名，不能使用测试集 |
| 修订监督 | B 阶段根据学生初稿和证据生成 critique、report、changed_claims |
| 质检 | 结构、引用、来源标签分歧、可选独立审查模型；默认一律 pending |
| 人工审核 | reviewer、时间、五项布尔检查、内容哈希；修改后须重新审核 |
| SFT-A | 六个 QA + 一个不带外部证据的完整观察报告 |
| SFT-B | 分开的批评与修订报告，复用推理的任务提示词和报告结构 |
| LoRA | 默认 dry-run；只在语言模型投影层加 LoRA，视觉编码器/连接器冻结；B 延续 A adapter，混入约 25% A 数据 |
| 可追溯性 | 数据/图片/索引指纹、生成调用记录、审核记录、训练配置与版本清单 |
| 原始模型基线 | 原 MAR 文件保留，新流程独立实现 |

## 不应夸大的验证范围

已实现并可离线测试：分组边界、盲化、教师响应回放、质检、人工审核、SFT 导出、A/B 预检、语言模块筛选和标签 loss mask。
离线回放使用模拟响应，不代表教师正确率；结构合格不等于证据真实。
当前本机没有 torch、transformers、peft；本次没有安装这些包，没有分词/模型前向/反向验证。
LoRA 真正训练和 GPU 适配需在模型、图片、硬件和依赖具备后另行验证。

仍待后续研究工作：网页正文与来源时效核验、案例实体/时间重排、独立人工六维评测、干预与消融、多种子实验和性能结论。
现有 split 只做精确文本与字节级图片去重；不能把它称为自动完成近重复图像或语义事件识别。
